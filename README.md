 Power Data Analytics Dashboard

A professional interactive data analytics dashboard built using Streamlit, Pandas, Plotly, and Machine Learning for analyzing electrical and sensor-related datasets such as Voltage, Current, Weight, and Power.

The dashboard allows users to upload CSV datasets and perform real-time data visualization, statistical analysis, correlation analysis, 3D plotting, and power prediction using Linear Regression.

🚀 Features
📂 Upload CSV datasets dynamically
📊 Interactive graph generation
Scatter Plot
Line Chart
Bar Chart
📈 Statistical summary of data
🎛 Sidebar filters for dataset customization
🌐 3D Data Visualization
🔥 Correlation Heatmap
🤖 Machine Learning based Power Prediction
📥 Download cleaned/filtered dataset
⚡ Fast and user-friendly Streamlit interface
